# TernGreefigh v0.2 prototype

Native Android Java + OpenGL ES 2.0. Landscape, 3D block humanoid, flat grid world,
third-person follow/orbit camera, analog joystick, jump, crouch, Halo, Murung and
ragdoll-style pose controls.

Important scope:
- This is an offline gameplay prototype, not an online multiplayer build.
- Ragdoll is currently a visual fall/tilt prototype, not a full joint-physics simulation.
- Character preview on the main menu is a placeholder; the actual 3D character is rendered in Play.
- Device-side visual testing is still required after installing the APK.

Build: GitHub Actions workflow `Build TernGreefigh APK`.
