# TernGreefigh

Prototype Android native Java project, package `com.tern.greefigh`.

- Landscape Android app
- OpenGL ES 2.0 renderer foundation
- Loading, menu, settings and basic gameplay overlay
- White/gray grid world foundation
- GitHub Actions APK workflow

Build in GitHub Actions with workflow `Build TernGreefigh APK`.

This is the first foundation build. Character movement, character mesh, camera orbit/follow, touch joystick, emotes and ragdoll are planned for subsequent prototype stages.
